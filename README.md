八卦搜索
划词搜索、拖拽搜索盘、功能转轮盘与常用网站入口，集中管理搜索、图片工具和本地配置。

主要功能

- 划词搜索：选中文字后，通过搜索框调用引擎库中已配置的网站。
- 拖拽搜索盘：文字、链接和图片分别使用独立的双圈布局，可在设置中调整。
- 功能转轮盘：提供内、中、外三圈功能位，可配置 OCR、图片搜图、二维码识别、输入搜索、分类搜索和常用网站。
- 搜索引擎库：统一管理搜索、视频、音乐、图片、翻译和常用网站；引擎库中的图标、名称、排序和启用状态会同步到搜索框、搜索盘和转轮盘。
- 自定义网站：支持添加搜索网站、网站直达和 AI 入口，并可按分类管理。
- 图片工具：支持图片压缩、尺寸调整、格式转换、裁剪、OCR、二维码识别和图片搜图。
- 本地配置备份：支持导出、导入和恢复设置，便于迁移或备份。

开始使用

1. 安装 Tampermonkey 等兼容的用户脚本管理器，并安装本脚本。
2. 刷新目标网页后，通过脚本管理器菜单打开“设置”。
3. 在“触发与显示”中调整搜索框、拖拽搜索盘和功能转轮盘的启用状态与快捷键。
4. 在“搜索引擎库”中管理网站、图标、分类和排序。
5. 在“图形搜索盘”和“功能转轮盘”中调整各圈功能位置。
