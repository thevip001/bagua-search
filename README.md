<h2>主要功能</h2>

<ul>
  <li><b>划词搜索：</b>选中文字后，通过搜索框调用引擎库中已配置的网站。</li>
  <li><b>拖拽搜索盘：</b>文字、链接和图片分别使用独立的双圈布局，可在设置中调整。</li>
  <li><b>功能转轮盘：</b>提供内、中、外三圈功能位，可配置 OCR、图片搜图、二维码识别、输入搜索、分类搜索和常用网站。</li>
  <li><b>搜索引擎库：</b>统一管理搜索、视频、音乐、图片、翻译和常用网站；引擎库中的图标、名称、排序和启用状态会同步到搜索框、搜索盘和转轮盘。</li>
  <li><b>自定义网站：</b>支持添加搜索网站、网站直达和 AI 入口，并可按分类管理。</li>
  <li><b>图片工具：</b>支持图片压缩、尺寸调整、格式转换、裁剪、OCR、二维码识别和图片搜图。</li>
  <li><b>本地配置备份：</b>支持导出、导入和恢复设置，便于迁移或备份。</li>
</ul>

<h2>开始使用</h2>

<ol>
  <li>安装 Tampermonkey 等兼容的用户脚本管理器，并安装本脚本。</li>
  <li>刷新目标网页后，通过脚本管理器菜单打开“设置”。</li>
  <li>在“触发与显示”中调整搜索框、拖拽搜索盘和功能转轮盘的启用状态与快捷键。</li>
  <li>在“搜索引擎库”中管理网站、图标、分类和排序。</li>
  <li>在“图形搜索盘”和“功能转轮盘”中调整各圈功能位置。</li>
</ol>
