# 八卦搜索

划词搜索、拖拽搜索和自定义快捷功能面板，将常用搜索网站与图片工具集中使用。

## 主要功能

- 划词搜索：选择文字后，通过图标搜索框调用已配置的网站。
- 拖拽搜索盘：文字、链接和图片使用各自的双圈功能布局，可在设置中调整。
- 功能面板：提供三页九宫格，可配置图片 OCR、图片搜图、二维码识别、输入搜索及网站入口。
- 自定义网站：支持添加搜索网站和网站直达，并管理分类、排序与功能面板入口。
- 图片工具：支持图片大小、尺寸及格式处理。
- 本地配置备份：支持导出和导入设置，便于迁移或恢复。

## 开始使用

1. 安装 Tampermonkey 等兼容的用户脚本管理器，再安装本脚本。
2. 刷新目标网页，通过脚本管理器菜单打开“设置”。
3. 在“触发与显示”中调整搜索框、拖拽和功能面板的启用状态及快捷键。
4. 在搜索引擎库中管理网站；在图形搜索盘和功能面板设置中调整功能位置。

## 图片功能

图片 OCR、图片搜图和二维码识别可通过选择本地图片或拖入图片开始操作。当前不提供直接截取屏幕的功能，也不要求安装额外的截图扩展。

部分识图网站尚未适配自动传图，需要在目标网站手动上传图片。调用第三方搜索或识图网站时，搜索内容或图片将按对应功能传递给所选服务，请留意隐私。

## 使用说明

- 图片复制、文件保存及第三方网站适配情况会受浏览器权限和目标网站变化影响。
- 用户自定义网站需要填写可用的网址；搜索网站需具备对应的搜索规则。
- 更新或迁移前，可以使用本地导出功能备份个人设置。
